# RuneHangul

A RuneLite plugin that translates Old School RuneScape into Korean (한국어).

Translations are made ahead of time and bundled with the plugin, so it works without any external translation service. See [docs/CONTEXT.md](docs/CONTEXT.md) for the background, design and plan (in Korean).
